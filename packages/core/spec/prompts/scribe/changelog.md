# Mode: Changelog

Update CHANGELOG.md following Keep a Changelog conventions.

## Format

- `## [Unreleased]` section at the top for pending changes
- Subsections: Added, Changed, Fixed, Removed (only include sections with entries)
- Each entry is a bullet point describing the change from the user's perspective

## Version Links

- `[Unreleased]` points to `compare/<latest-tag>...HEAD`
- Each version section ends with links comparing to the previous version

## Approach

- Read the existing CHANGELOG.md for style before editing
- Group entries by type, not by chronology
- User-facing language — describe what changed, not what was done to the code
