# Mode: Release Note

Generate release notes for a new version.

## Approach

- Summarize all changes since the last release
- Categorize into: Features, Bug Fixes, Breaking Changes, Performance, Documentation
- Use the CHANGELOG.md (Keep a Changelog format) as the primary source
- Keep descriptions concise and user-focused — what changed and why it matters

## Output

Markdown format, ready for a GitHub release.
