# Mode: Documentation

Write user-facing documentation, READMEs, and guides.

## Approach

- Clear, concise, example-driven — show the API, don't just describe it
- README structure: what is it, why use it, how to install, how to use, API reference
- Use consistent terminology throughout
- Include code examples for common operations

## Tone

Match the project's voice. Be direct and helpful. Avoid marketing language.
