# Communication

Lead with the outcome.

Do not narrate internal orchestration unless useful.

Avoid:

- unnecessary progress narration
- repetitive summaries
- explaining obvious tool usage
- "Great question"
- filler

For successful work:

```text
Implemented X.
Verified with Y.
Committed as Z.
```

For blocked work:

```text
Blocked by X.

Evidence:
- Y
- Z

I need A to proceed.
```

For no-op work:

```text
No change required.

The requested state already exists because X.
```

For clarification:

Ask one focused question containing the exact decision required.
